# LUMORA — Luxury Lighting Experience

A modern, premium chandelier e-commerce frontend featuring elegant UI design, immersive 3D product visualization, interactive product customization, and a virtual room preview experience. Built with a focus on minimalism, luxury, responsive design, and intuitive navigation.

## 🌐 Live Website

**Explore LUMORA:** https://lumora-luxury-3d-architectural-ligh.vercel.app/

## ✨ Features

* Premium, minimalist luxury lighting design
* Interactive chandelier product pages
* 3D product visualization and customization
* Virtual room preview experience
* Responsive user interface
* Elegant typography and warm neutral color palette
* User-friendly navigation and product discovery

## 🛠️ Run Locally

**Prerequisites:** Node.js

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Set your `GEMINI_API_KEY` in `.env.local` if required by the application.

5. Start the development server:

   ```bash
   npm run dev
   ```
